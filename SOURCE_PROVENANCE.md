# Source provenance

Renkin's production implementation is authored in this repository and licensed
under Apache-2.0. The release assembler transpiles those production modules and
emits their declarations without bundling external dependencies. Git commit history
records the changes to Renkin; release validation records identify the assembled
source commit and exact tarball digest.

## Behavioral references

The implementation was checked against these source snapshots to understand the
required behavior. They are references, not vendored packages or a claim that their
entire source is incorporated into Renkin:

| Reference | Source revision | Use |
| --- | --- | --- |
| Alchemy | `82b7fc24c03db868772a60bb2927054582d22f43` | Worker/resource behavior, migration history, native runtime and website semantics |
| Delimoov | `cb885863bb6b91901865700bb947c84742aae069` | Required application graph, migration inputs, preview lifecycle and build expectations |

Alchemy's root license at that snapshot is Apache-2.0; its NOTICE attributes
Copyright 2026 Functionless Corp. and points to its third-party extraction records.
Renkin does not copy that NOTICE as if Alchemy were included: no Alchemy runtime
source or package is vendored by this release. No root license file was present in
the inspected Delimoov snapshot; it is not distributed as Renkin source. Repository
tooling conventions were adapted to the user's project requirements; these files
are not included in the public runtime artifact.

No third-party runtime source extraction is declared by this implementation.
Any future extraction must add its exact source files/revision, applicable upstream
license and notices, and the modification record before code is copied. Matching
a project's top-level license is not a substitute for reviewing its extracted code.

## Generated and external files

- Example `routeTree.gen.ts` files are generated by TanStack Router from the example
  routes. They are fixtures and are not included in the runtime package.
- Release JavaScript/declarations are mechanically generated from Renkin TypeScript;
  the generated manifest points only to those emitted files.
- Native workerd code generated by Renkin's wrappers comes from Renkin's own source.
  Astro/TanStack compilation is performed by external framework dependencies; their
  generated application output belongs to the consumer and is not bundled into Renkin.
- Distilled, Effect and platform/framework dependencies remain external packages;
  their license metadata is documented in THIRD_PARTY_NOTICES.md. Renkin does not
  replace their upstream license files or bundle a second Effect runtime.

  <https://www.apache.org/licenses/LICENSE-2.0.txt> on 2026-09-21.
