# Websites

This package composes TanStack Start Solid SPA/SSR builds with Renkin Workers and
native local bindings. Consumers use `renkin/cloudflare`, `renkin/vite`, and the
root `renkin` API. See [TanStack sites](../../docs/tanstack-sites.md).

The framework owns compilation, prerendering, assets and development reload.
Renkin owns resource dependencies, native handles, publication and cleanup. The
shared structural `WorkerBuildRecipe` returns the same `WorkerBuildResult` used
by ordinary Workers and external builders. Raw builder output is wrapped with
per-resource binding metadata after compilation; it must not be cached together
with a different site's binding declaration. Build reuse belongs to the next
build-cache task.

Production uses the official Cloudflare Vite plugin and its workerd prerender
preview. The plugin currently depends on Miniflare 5 alpha; Renkin's application
runtime remains the separately pinned stable Miniflare 4. Development runs Vite's
Solid server in Bun and obtains actual native handles from Renkin's local graph.
It does not start a second Cloudflare plugin runtime. The request bridge scopes
`cloudflare:workers` bindings and `waitUntil` to each request, and routes local
S3 URLs to the native gateway before frontend fallback.

No Alchemy dependencies or source copies are used. Official dependencies retain
their package licenses. `routeTree.gen.ts` in the examples is generated by the
TanStack Router plugin and excluded from Biome; do not hand-edit that output.
