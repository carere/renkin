# Project agent skills

`AGENTS.md` routes agents to these repository-local skills:

| Skill | Purpose | Source |
| --- | --- | --- |
| `renkin-testing` | Observable behavior, ownership and Effect test validation. | Adapted from Delimoov's TDD skill and coding standard. |
| `renkin-release` | Upstream extraction and validation of the single published artifact. | Renkin's agreed architecture and release constraints. |
| `writing-for-agents` | Maintain concise agent instructions and skill routing. | Copied with its mechanics reference from Delimoov. |

Delimoov's issue workflows, domain models, frontend design skills and application
implementation workflows are omitted because they do not serve this foundation.
Browser and Cloudflare implementation skills can be added when that work begins.
